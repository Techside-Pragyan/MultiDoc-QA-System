# MultiDoc QA System

**An AI-powered full-stack application that lets you upload your documents and instantly chat with them.**

MultiDoc QA acts as your personal, interactive knowledge base. Simply upload your files (PDFs, Word documents, text files, or presentations) and use the built-in AI chat interface to ask questions, extract key insights, and find specific answers directly from your own data.

### ✨ Key Features
- **📚 Multi-Format Support:** Upload PDFs, DOCX, TXT, and PPTX files.
- **🤖 Smart AI Chat:** Ask natural language questions and get accurate answers based strictly on your uploaded documents.
- **🔐 Secure User Authentication:** Create an account and manage your own private knowledge base.
- **🎨 Premium UI:** Enjoy a beautiful, modern, and highly responsive frontend built with React and glassmorphism aesthetics.
- **⚡ Fast Backend:** Powered by FastAPI, FAISS vector search, and LangChain for instant, context-aware AI responses.

### 🛠️ Tech Stack
- **Frontend:** React, Vite, React Router, Framer Motion, Axios
- **Backend:** Python, FastAPI, SQLAlchemy, SQLite, LangChain, FAISS, HuggingFace Transformers
